# 🚀 Guía de Instalación — ProjectJaina_MemoryGuard

## Requisitos Previos
* Cliente World of Warcraft 3.3.5a (Build 12340), recomendado especialmente para clientes con texturas HD/FHD de gran tamaño.

## Instrucciones
1. Clona o copia la carpeta `ProjectJaina_MemoryGuard` en:
   ```text
   Interface\AddOns\ProjectJaina_MemoryGuard\
   ```
2. Inicia el cliente del juego.
3. Comprueba el mensaje de bienvenida en el chat: `[MemoryGuard] v1.0.0 Activo • Blindaje Anti-OOM FHD operacional.`
